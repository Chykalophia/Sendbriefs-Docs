## Uploading

Drag files onto the page, or click **Choose Files**. Images, documents (PDF, Office), videos and more are supported, and the file type is detected for you.

Files uploaded on a client's page, or for a client's logo, are filed under that client automatically. They appear in the client's **Assets** card on its [Overview](/app/clients/#overview).

## Finding files

Search by name, description or tag, and filter by type and client. **Refresh** reloads the list.
