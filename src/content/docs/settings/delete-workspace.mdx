<aside class="sb-tldr">
  <p class="sb-tldr-label">TL;DR</p>
  Deleting a workspace permanently removes all its clients, briefs, contacts and data. It can't be
  undone. Only the owner can do it.
</aside>

<Screenshot
  src="/screenshots/app/settings-danger.webp"
  dark="/screenshots/app/settings-danger-dark.webp"
  alt="Settings, Delete workspace: a Danger Zone card warning that deleting is permanent, a box asking you to type the workspace name to confirm, and a Delete Workspace button."
/>

1. Go to **Settings → Delete workspace**.
2. Type the workspace name exactly as shown.
3. Click **Delete Workspace**.

If you pay for a plan, check [Plan and billing](/settings/plan-and-billing/) before you delete.
