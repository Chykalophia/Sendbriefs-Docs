<aside class="sb-tldr">
  <p class="sb-tldr-label">TL;DR</p>
  Open <strong>Settings</strong> in the sidebar. The left-hand menu groups every workspace setting
  into six areas. Owners and managers can change settings; members can see them. Your personal
  preferences are in <a href="/app/profile/">Profile</a>, not here.
</aside>

Each settings page has its own address, `/settings?tab=<name>`, so you can bookmark or share it.

## Workspace

| Page                                            | What you set                                                                     |
| ----------------------------------------------- | -------------------------------------------------------------------------------- |
| [General](/settings/general/)                   | Workspace name, subdomain, date format, workspace-wide overrides, custom domain. |
| **Team**                                        | Opens [Team](/app/team/).                                                        |
| [Security](/settings/security/)                 | Require two-factor authentication, session timeout, IP allowlist.                |
| [Delete workspace](/settings/delete-workspace/) | Permanently delete the workspace. Owner only.                                    |

## Brand

| Page                                          | What you set                                                       |
| --------------------------------------------- | ------------------------------------------------------------------ |
| [Logo and colors](/settings/logo-and-colors/) | Workspace logo, brand colours, and the client portal landing page. |
| [Client portal](/settings/client-portal/)     | Turn the portal on, access tier and link expiry.                   |
| [Media library](/settings/media-library/)     | Images and files used in briefs.                                   |

## Briefs and templates

| Page                                        | What you set                                                   |
| ------------------------------------------- | -------------------------------------------------------------- |
| [Templates](/settings/templates/)           | Report templates that new briefs are built from.               |
| [Writing styles](/settings/writing-styles/) | How the AI writes when drafting a section.                     |
| [Approvals](/settings/approvals/)           | Whether briefs need approval before sending, and who approves. |
| [Scheduling](/settings/scheduling/)         | Recurring schedules that make each client's drafts.            |

## Delivery

| Page                                      | What you set                                                                                  |
| ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| [Email sending](/settings/email-sending/) | Sender name and address, your own sending provider, engagement tracking, suppressed contacts. |
| [Email layout](/settings/email-layout/)   | How brief emails look.                                                                        |
| [Notifications](/settings/notifications/) | Which team notifications are sent in-app and by email.                                        |

## Integrations and billing

| Page                                                | What you set                                      |
| --------------------------------------------------- | ------------------------------------------------- |
| [Connected accounts](/settings/connected-accounts/) | Google Analytics, ClickUp and other data sources. |
| [Plan and billing](/settings/plan-and-billing/)     | Plan, add-ons, payment and invoices. Owner only.  |
