| Service              | What it does                                                                                                |
| -------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Google Analytics** | Pulls GA4 metrics (sessions, users, engagement and more) into data fields.                                  |
| **ClickUp**          | Turns a list's recent tasks into Completed, In progress, Blocked and Up next lines, and pulls task metrics. |
| **Slack**            | Coming soon.                                                                                                |

## Setting it up

1. Click **Connect** and sign in to the service.
2. Open a client's [Overview](/app/clients/#overview) and add a **data stream**: pick the GA4 property or ClickUp list for that client. Data sources are linked per client so one client's numbers never land in another's brief.
3. In the brief editor, use **Sync** to pull the latest data, or **Pull from ClickUp…** / **Import recent work from ClickUp…**. See [The brief editor](/app/brief-editor/#top-bar).
