## Search

Open it with **⌘K** / **Ctrl+K** or the **Search** box at the top of the sidebar. Start typing a client, brief, contact or setting name. Results are grouped:

| Group             | Examples                                                                                                                           |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Brief**         | Create the next brief for a client and open it, create a one-off brief, or open the New brief page with the client already picked. |
| **Actions**       | New brief, **Add an update** for a client, add a client.                                                                           |
| Pages and records | Matching briefs, clients, contacts and settings pages.                                                                             |

Use ↑ ↓ to move, Enter to choose, Esc to close.

## Keyboard shortcuts

Single-key shortcuts work on pages such as [Due briefs](/app/due-briefs/#keyboard). If you use speech input or press keys by accident, turn them off in [Profile → Keyboard shortcuts](/app/profile/). ⌘K always works.
