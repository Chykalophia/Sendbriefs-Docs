## The list

Each row is one client with its template, the period the brief covers, and how late it is. Every row starts ticked.

When a client has missed more than one period, the row shows each period as a button (for example **Oct 12 to 18** and **Nov 9 to 15 (due now)**). Pick the one you want to make now.

If a client already has a draft open for the period, the row says **Draft already open · joins the run at the end**: no new draft is made, and the existing one is added to the end of your writing run.

Clients without an active schedule aren't listed. **Tidy up clients** helps you give them one. See [Clients](/app/clients/#tidy-up-clients) and [Scheduling](/settings/scheduling/).

## Make the drafts

| Button                       | What it does                                                                                                                                                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Make N and start writing** | Creates the ticked drafts and opens the first in the editor. A bar at the top of the editor shows your place in the run: **Done, next →** saves and opens the next brief, **Finish** ends on the last one, and **Leave the run** stops early. |
| **Just make the drafts**     | Creates the drafts and leaves them in [Briefs](/app/briefs/) for later.                                                                                                                                                                       |

## Keyboard

| Key   | Action                                   |
| ----- | ---------------------------------------- |
| ↑ ↓   | Move between clients                     |
| X     | Tick or untick the current client        |
| ← →   | Change the period for the current client |
| Enter | Make the drafts and start writing        |
