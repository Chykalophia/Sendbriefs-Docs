## Header

| Button                | What it does                                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Preview Email**     | Opens the [email preview](#email-preview): the brief exactly as the email will look.                                     |
| **Preview in Portal** | Opens the brief in the [client portal](/app/client-portal/) as a client sees it. Once sent, it reads **View in Portal**. |
| **Download PDF**      | Saves the brief as a PDF.                                                                                                |
| **Edit Report**       | Opens the [editor](/app/brief-editor/).                                                                                  |
| **Delete**            | Deletes the brief after you confirm.                                                                                     |

## Report details

**Reporting period**, **Deadline** and the deadline status (**On track**, **Due soon** or **Overdue**), when the brief was created and last changed, and its version. A brief with no deadline is due 5 days after its period ends.

## Status and actions

The row of buttons above the brief changes with its status. You only see the actions your role allows; see [Team → Brief permissions](/app/team/#brief-permissions).

| Status                | Buttons                                        |                                                                                                |
| --------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Draft**             | **Submit for review** or **Send**              | Submit when approval is required, otherwise send.                                              |
| **Pending approval**  | **Approve**, **Request changes**, **Withdraw** | Reviewers approve or send it back. The author can withdraw it to keep editing.                 |
| **Changes requested** | **Resubmit for review**, **Move to draft**     | The reviewer's note shows in a yellow panel with a link to the editor.                         |
| **Approved**          | **Send**, **Unapprove**                        | Unapprove returns it to draft so it can be edited again.                                       |
| **Sent**              | **Send update**, **Resend…**                   | Shown to owners and managers. **Send update** appears when a sent brief was edited afterwards. |

## Send readiness

The card on the right lists what has to be true before the brief can go out:

- Brief has content
- Report period is set
- At least one recipient contact for the client
- All required data fields are filled
- Report has been approved (when approval applies)
- No open must-fix feedback

A cross marks anything still open. Send stays disabled until every item passes.

## Activity log

Who changed what in this brief, newest first. The full record is on **Audit history**.

## Send this brief

<Screenshot
  src="/screenshots/app/brief-send-full.webp"
  dark="/screenshots/app/brief-send-full-dark.webp"
  alt="The Send this brief page: Recipients with a checkbox per client contact, a Before it goes checklist with every item Ready, and a Check and send box listing the recipients, When: Right away, and a 'Send to 2 people' button. On the right, an Open email preview button."
/>

**Send** opens a page of its own. It says up front: nothing goes out until you press the button at the bottom.

1. **Recipients**: the client's contacts, all ticked. Untick anyone who shouldn't get this one. **Manage contacts** opens the client's contact list.
2. **Before it goes**: the same readiness checks, each marked **Ready** or **Needs a look**.
3. **Check and send**: who it goes to and when (**Right away**). If a data token in the brief has no value, you're warned that it will show as "—" and can **Send anyway** or go back.
4. **Send to N people** sends it.

A contact never gets the same brief twice from this page; to send it again, use **Resend…** on the brief page. **Open email preview** on the right shows the email first.

To change how the email looks, see [Email layout](/settings/email-layout/). To change the sender name and address, see [Email sending](/settings/email-sending/). The email itself is described in [Client emails](/emails/client-emails/#the-brief-email).
